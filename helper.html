划懂 ChatGPT 本机助手

ChatGPT 登录模式需要 macOS 与 Node.js 22 或更高版本。Windows、Linux 用户目前请使用 API Key 模式；API 费用独立于 ChatGPT 订阅。

  1. 从 Node.js 官网安装 Node.js 22 或更高版本。
  2. 从发布页下载与你安装的商店插件 ID 对应的 macOS 助手包。若尚未提供安装包，请等待商店版本发布。
  3. 解压，在终端输入 node （末尾有空格），将包中的 install.mjs 拖入终端，回车。不需要 sudo。
  4. 重新启动 Chrome，在划懂设置中选择 ChatGPT 登录，完成授权。

安装器只配置指定插件 ID，并保留已有的划懂授权 ID 和登录记录。如果移动或删除 Node.js，需要重新安装助手。账户资格与可用额度以 OpenAI 实际返回为准。

卸载

先在插件设置中退出 ChatGPT，并在 ChatGPT 设置中撤销授权。关闭 Chrome，删除 ~/Library/Application Support/Huadong/ 和 ~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.huadong.chatgpt.json。这会删除本机助手保存的账户信息。

English

ChatGPT sign-in requires macOS and Node.js 22+. Windows and Linux users can use API key mode, billed separately from ChatGPT subscriptions.

  1. Install Node.js 22+ from the official website.
  2. Download the macOS helper matching the store extension ID from Releases. If no package is available yet, wait for the store release.
  3. Extract the archive. In Terminal, type node , drag install.mjs into the terminal, and press Return. No sudo is required.
  4. Restart Chrome, then sign in from Huadong settings.

Reinstall if you move Node.js. Existing Huadong extension permissions and sign-ins are preserved. To uninstall, sign out and revoke authorization, quit Chrome, then remove the two paths listed above. This deletes locally stored account information.
