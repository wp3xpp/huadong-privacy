划懂隐私政策

1. 功能与数据处理 划懂用于解释用户在网页中主动选中的文字。点击解释、继续追问或重新解释时，选中文字、可选附近正文、当前对话内容及模型设置会发送给 OpenAI 以生成回答。默认最多提取 4,000 字符选区及 6,000 字符附近正文，用户可以查看或关闭附近上下文。

2. 联网搜索 解释涉及最新或实际数据时，OpenAI 的搜索工具可能处理为该问题生成的搜索词并检索第三方来源。搜索由 OpenAI 服务执行，适用其相关政策；划懂不承诺搜索提供方不会保留其接收的数据。点击来源链接时，由浏览器打开第三方网站并适用该网站的隐私政策。

3. 登录和密钥 使用 API Key 时，Key 由扩展存储在本机或当前浏览器会话，用于验证 OpenAI 请求，不通过 Chrome 同步。使用 ChatGPT 登录时，账户标识、邮箱和登录令牌由本机助手保存，用于显示账户、登录续期和调用授权服务。网页无法直接读取扩展可信存储中的 Key，但本机存储并非加密保险箱。

4. 本地数据和保留 扩展保存偏好及逐站授权信息。对话保存在当前页面内存，刷新或关闭页面后不作为长期历史保存。主动下载的图表由用户保存在自己的设备中。划懂没有自建的对话收集服务器，也没有广告或行为分析服务。OpenAI 对请求及登录数据的处理遵循其隐私政策及用户对应服务条款；扩展不控制其保留期限。

5. 共享与用途 数据仅用于用户请求的解释、搜索、账户验证及相关功能。划懂不出售用户数据，不用于广告投放、信用评估或放贷。用户主动选中的材料可能包含个人或敏感信息，只有在需要时才应将其发送给模型服务。

6. 控制与删除 用户可以清除 API Key、退出 ChatGPT 登录、撤销网站权限或卸载扩展。退出登录会删除本机助手保存的令牌并尝试远端撤销授权；若远端撤销失败，应在 ChatGPT 的授权设置中断开连接。本机助手是独立程序，卸载 Chrome 扩展不自动删除助手和账户元数据；完整删除需按助手卸载说明清理。OpenAI 保存的数据需按其账户与隐私工具管理。

7. Limited Use 划懂对用户数据的使用与传输遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求，不用于与本扩展单一用途无关的目的。
